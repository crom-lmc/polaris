审计原则：登录动作 + 所有登录才能做的动作，全部记录——GET 也算。
① 登录成功/失败由 sso-auth 经内部接口上报（含失败原因、登录方式、IP、UA），与原 sso_login_log 双写过渡；② 网关 JwtAuthFilter 对验签通过后的每个请求（含 GET 列表/详情/翻页）统一兜底记录：应用 / HTTP 方法 / 路径 / 操作人 / IP / UA；③ 内部 Feign 调用（/internal/**） 无登录主体，操作人统一填 SYSTEM，业务方可透传触发它的真实用户覆盖；④ polaris-sso-client · AuditApi 补充业务语义，全部落库 sso_audit_event。写入失败只告警，不阻断业务。
全量记录的成本控制：网关侧异步批量上报（WebClient 不阻塞业务线程），表按 (created_at, app, operator) 建索引，保留 180 天并按天清理；普通 GET 只记访问事实，敏感读（导出、查看明文薪资）由业务层补记详情。
